Overview

How to make full backups, clone disks, and steps to recover data using common tools and live USB environments.

Tools

  • External USB drive for backups
  • Cloning tools (Clonezilla, dd)
  • Recovery tools (TestDisk, PhotoRec)

Steps

  1. Create a full disk image or clone the drive before attempting recovery operations.
  2. Use read-only or non-destructive recovery tools where possible.
  3. For deleted files, try TestDisk/PhotoRec from a live USB; for filesystem corruption, prefer filesystem repair tools after imaging the drive.
