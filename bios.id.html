BIOS/firmware & reset

Perbarui BIOS dengan aman, pulihkan dari pembaruan buruk, dan lakukan reset NVRAM/CMOS.

Beranda • Tutorials

Ikhtisar

Tutorial ini menjelaskan kapan memperbarui firmware, bagaimana mempersiapkan pembaruan, dan cara memulihkan jika pembaruan gagal.

Peringatan

  • Hanya gunakan firmware dari pabrikan untuk model Anda.
  • Pastikan baterai terisi dan terhubung ke sumber daya yang andal selama pembaruan.
  • Ikuti instruksi pembaruan pabrikan secara tepat.

Langkah pemulihan

  1. Jika sistem tidak bisa boot setelah pembaruan, coba reset CMOS (lihat manual model untuk jumper atau langkah melepas baterai).
  2. Beberapa pabrikan menyediakan alat pemulihan BIOS atau citra USB pemulihan — ikuti proses yang didokumentasikan.
  3. Jika motherboard tidak merespons, minta perbaikan profesional; pemulihan firmware bisa bersifat hardware-spesifik.
