Keyboard replacement & key repair

Replace keyboard modules or repair sticky/missing keys.

Home • Tutorials

Overview

Learn how to remove keycaps, clean under keys, replace individual scissor/rubber domes, or swap the entire keyboard module.

Tools

  • Keycap puller or thin plastic tool
  • Compressed air and isopropyl alcohol wipes
  • Screwdriver set for keyboard module removal

Steps

  1. Power down, unplug, and remove battery if possible.
  2. Remove keycap carefully using a keycap puller or flat plastic tool.
  3. Clean debris and spills with compressed air and alcohol wipes; allow to dry fully.
  4. If a key switch or dome is broken, replace the small parts where possible.
  5. For full keyboard replacement, remove the keyboard module screws, disconnect the ribbon cable, and install the new module.
  6. Reassemble and test all keys. Use an online keyboard tester to confirm all scancodes are correct.
