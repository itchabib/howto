Analytics

This site does not currently track visitors. If you choose to enable analytics, consider a privacy-friendly provider (for example, Plausible, Fathom, or a self-hosted Matomo instance) and configure it to anonymize IP addresses and minimize data collection.

If you prefer to use Google Analytics, add the tracking snippet to the <head> of pages and include a clear privacy notice here with an opt-out mechanism.

/* Example (do not include without replacing UA/ID):
<!-- Google Analytics snippet -->
<script async src="https://www.googletagmanager.com/gtag/js?id=UA-XXXXX-Y"></script>
<script>window.dataLayer = window.dataLayer || []; function gtag(){dataLayer.push(arguments);} gtag('js', new Date()); gtag('config', 'UA-XXXXX-Y', { 'anonymize_ip': true });</script>
*/

Data

No personal data is collected by default. The site uses client-side scripts for search and language detection; these operate in the browser only and do not send data to third parties.
