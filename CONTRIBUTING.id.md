# Cara Berkontribusi

Terima kasih atas minat Anda untuk memperbaiki panduan ini.

- Tambahkan instruksi spesifik model, foto, atau koreksi melalui pull request.
- Simpan gambar di folder `assets/` dan sertakan teks alt yang deskriptif.
- Tulis pesan commit yang jelas dan buka PR kecil untuk setiap perubahan logis.

Jika Anda menerjemahkan konten, tambahkan file dengan akhiran `.id.html` untuk halaman bahasa Indonesia dan sertakan README.id.md yang menjelaskan status terjemahan.
