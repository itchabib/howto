# How to Service a Laptop

This repository contains a simple, static website that explains how to service a laptop safely: cleaning, thermal paste replacement, minor upgrades, and testing. The site is intentionally simple so it can be hosted on GitHub Pages.

Getting started

1. Open the site locally: open `index.html` in your browser.
2. Enable GitHub Pages to publish the site: go to your repository Settings → Pages, select branch `main` and folder `/ (root)`, then save. The site will be published at:

   https://itchabib.github.io/howto/

What I added

- index.html — main guide (already added)
- styles.css — styling and responsive layout
- cleaning.html — deeper instructions for cleaning fans and vents
- thermal-paste.html — guide to replacing thermal paste safely
- upgrades.html — notes about upgrading RAM and storage
- assets/diagram.svg — small inline diagram used by the guides
