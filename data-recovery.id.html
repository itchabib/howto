Cadangan & pemulihan data

Clone drive, pulihkan file yang dihapus, dan gunakan live-USB untuk penyelamatan.

Beranda • Tutorials

Ikhtisar

Cara membuat cadangan penuh, meng-clone disk, dan langkah untuk memulihkan data menggunakan alat umum dan lingkungan live USB.

Alat

  • Drive eksternal USB untuk cadangan
  • Alat cloning (Clonezilla, dd)
  • Alat pemulihan (TestDisk, PhotoRec)

Langkah-langkah

  1. Buat citra disk penuh atau clone drive sebelum mencoba operasi pemulihan.
  2. Gunakan alat read-only atau non-destruktif bila memungkinkan.
  3. Untuk file yang dihapus, coba TestDisk/PhotoRec dari live USB; untuk korupsi sistem file, gunakan alat perbaikan setelah membuat image dari drive.
